# Libertad financiera

Repositorio personal: aprendizaje, plan de inversión y plan de negocio hacia
la libertad financiera.

## Contexto

Perspectiva de un médico hematólogo. Objetivo: construir una empresa de medicina estética/antiaging en Mallorca en 3-5 años, mientras se gestiona un ahorro mensual constante durante los próximos 4 años.

Este repo tiene tres partes, pensadas para leerse en orden pero que
funcionan de forma independiente. Cada una tiene un núcleo (las
decisiones ya tomadas) y un bloque "para profundizar" con mucho más
contenido pensado para un año de estudio — ver el
[Plan de estudio](plan-de-estudio.md) para un calendario sugerido.

## [01 — Fundamentos de economía](01-fundamentos-economia/README.md)

Conceptos básicos de macro y micro, mercados financieros, fiscalidad en
España, y activos alternativos (arte, coleccionismo). Con enlaces a
fuentes serias para profundizar en cada tema.

## [02 — Portfolio y plan de inversión](02-portfolio-inversion/README.md)

Política de inversión a 4 años para el ahorro mensual: núcleo indexado
(SP500/global) + satélite de acciones individuales y cripto, con un
"cubo" aparte reservado para financiar el negocio. Proyecciones numéricas
y fiscalidad de plusvalías.

Es un documento de estrategia. La ejecución (cálculo de reparto mensual,
seguimiento de cartera real y simulacro) vive en el proyecto separado
Supertrader.

## [03 — Negocio: medicina estética](03-negocio-medicina-estetica/README.md)

Plan de empresa para una clínica de medicina estética/antiaging en
Mallorca: análisis de mercado, modelo de negocio, marco legal sanitario
español, estructura societaria entre socios, marca personal/red de
contactos, ventaja de automatización con IA, y proyección financiera.

## Notas

- Las cifras que aparecen son ilustrativas, no datos reales de nadie.
- Los documentos son un punto de partida para pensar y decidir, no
  asesoramiento legal, fiscal o de inversión profesional. Antes de
  ejecutar cualquier parte (sociedad, licencias sanitarias, fiscalidad),
  validar con un asesor/gestor cualificado.
